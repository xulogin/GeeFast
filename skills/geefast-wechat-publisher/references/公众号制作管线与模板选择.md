# GeeFast 公众号制作管线与模板选择

这是一套从遥感实验结果到微信公众号草稿箱的完整流程。文章内容、图片、封面和日志只写入工作区；E 盘公众号项目只读参考，GeeFast GitHub 只发布插件和技能，不放公众号正文、图片、配置或凭据。

## 一、内容生产主线

```text
研究结果/测速记录
  → 提炼事实口径
  → 写 Markdown 初稿
  → 生成原理图、速度图、进度图
  → 设计 1:1 封面并设置中心安全区
  → 中文标点检查
  → WeChatPub 主题排版
  → HTML、图片、脱敏检查
  → 上传正文图片和封面
  → 创建微信公众号草稿
  → 后台手机预览
  → 用户手动发布
```

## 二、写作口径

1. 把“完整研究区实测”“当前进度”“前测估算”分开写，不能把瓦片测速写成整景完成时间。
2. 昆明 Landsat 单景 4.69 秒可以写实测；全球 MODIS 的 46–49 GB、10–25 分钟只能写前测估算，除非长跑真的完成并有日志。
3. 解释 48 MiB 是 `getPixels/computePixels` 单次交互请求边界，不是整幅影像大小上限。
4. 不写多账号规避配额，不把合法切块并发说成破解 GEE。
5. 不暴露本机绝对路径、用户名、项目 ID、AppSecret、token、OAuth、虚拟环境路径。

## 三、文章结构模板

1. 标题：结果导向，少用内部项目名；本篇标题为“GEE遥感数据高速下载到本地，免安装直接用”。
2. 开头：先给速度和数据规模，再说明这是实测还是估算。
3. 安装：面向普通用户，直接写“在 Codex 或 Claude 中说：帮我安装 https://github.com/xulogin/GeeFast”。
4. 使用：给一个本地研究区示例；说明 GeeLo 可以把研究区上传 Asset、写代码、运行、挑错并迭代到跑通，再由 GeeFast 下载。
5. 原理：原生投影、自动安全切块、合法并发、重试、本地 GeoTIFF 写入。
6. 实测：昆明单景和 MODIS 大任务，明确数据口径。
7. 边界：geedim、Export to Drive、复杂合成、配额和 BigTIFF。
8. 系列：GeeLo（打通本地和云端的全自动管线）、GeeFast（高速下载到本地）、GeeDL（让 GEE 可以做深度学习）、GeeZip（让数据可以压缩下载）。

## 四、配图模板

- 原理图：展示“原生投影 → 安全瓦片 → 并发请求 → 本地窗口写入”。
- 速度图：展示不同路线耗时，并注明昆明完整研究区、波段数、分辨率和瓦片数。
- 进度图：展示 MODIS 瓦片数、单块耗时、估算区间；估算必须在图上标注。
- 图片文件使用相对引用，例如 `素材/01_高速下载路线.png`，不写电脑绝对路径。

## 五、封面设计与安全区

封面输出为 1:1 PNG，但不能把重要文字贴近边缘，因为公众号列表、分享卡片和推荐位可能按横向比例裁切。

封面设计规则：

- 主标题和副标题放在画面中央 15%–85% 的安全矩形内。
- 四周只放卫星、地球、网格、云端图层、下载箭头等可被裁掉的装饰。
- 标题必须完整可读，避免复杂小字、Logo、水印和人物。
- 封面至少保留旧版本，采用新文件名生成安全区版，确认后再上传。

本篇最终封面：`微信草稿/GeeFast_GEE高速下载/封面_GEE高速下载_安全区.png`。

## 六、WeChatPub 模板选择

默认使用 `wechatpub-format` 的 `interview`：技术文章有清晰层级、阅读节奏稳定，正文、代码、图片和数据段落都不喧宾夺主，适合本篇“实验记录 + 工具教程”。

| 主题 | 适用文章 | 本篇是否优先 |
|---|---|---|
| `interview` | 技术访谈、实验记录、工具教程，层级清楚 | 是，当前默认 |
| `github` | 开源项目、代码、安装命令、仓库介绍 | 适合安装说明特别重的文章 |
| `bytedance` | AI、云计算、速度测试、现代科技产品 | 适合更强科技感的速报 |
| `newspaper` | 深度分析、长文、研究报告 | 适合理论和方法综述 |
| `magazine` | 长篇专题、强留白、品牌化栏目 | 适合系列总览 |
| `wechat-native` | 传统公众号阅读、稳妥简洁 | 需要保守排版时使用 |

选择顺序：先看内容形态，再选主题；不要为了填满版面强行增加卡片、表格或引用框。技术实测优先保证数据可读性和图片顺序。

## 七、实际命令链

```text
zh_punctuation_fix.py --write
format.py --input 推文.md --theme interview --output 排版输出 --no-open
检查 article.html：图片、内联样式、脚本、外链 CSS、绝对路径
publish.py --dir 排版输出/推文 --cover 封面_GEE高速下载_安全区.png --title ... --author 一秋 --yes
```

配置读取顺序：`WECHATPUB_CONFIG` → `~/.wechatpub/config.json` → 技能目录配置。凭据只读使用，不复制到项目或日志。

## 八、发布边界与验收

- 只调用草稿箱接口，不群发、不定时发送。
- 发布日志脱敏保存到工作区。
- 验收正文标题、封面、图片顺序、代码块、手机裁切和估算标注。
- 旧草稿默认不删除，避免误删；确认新草稿无误后由用户在后台自行处理旧稿。
